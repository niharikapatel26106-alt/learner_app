# Learner App 📚

A Flutter mobile application designed to provide a simple learning experience with user authentication, API integration, local data persistence, settings, favorites, profile management, and notifications.

## 🚀 Features

- User Signup
- User Login
- Form Validation
- Home Screen
- Learning Content from REST API
- Detail Screen
- Favorites
- Profile
- Local Data Persistence
- Settings Menu
- Theme Settings
- Notification Settings
- Local Notifications
- Logout Functionality

## 🛠️ Technologies Used

- Flutter
- Dart
- REST API
- JSON
- SharedPreferences
- flutter_local_notifications
- HTTP

## 🔗 API

The application uses **JSONPlaceholder** as a demonstration REST API to fetch learning-related content.

## 💾 Local Storage

The application uses **SharedPreferences** to store simple user data and application preferences locally.

## 🔔 Notifications

The application demonstrates local notification functionality, including notification configuration and testing.
